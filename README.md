# course-agent-skills-in-action
Give your AI superpowers! 🚀 A hands-on workshop on Agent Skills and SKILL.md, from reusable prompts to private knowledge and real code execution. Learn by building three practical demos.

## What's inside

| Path | What it is |
|---|---|
| `slide/` | The Slidev deck — `cd slide && npm install && npm run dev` (press `P` for presenter mode) |
| `demos/` | Hand-out skills: `demo-0/emoji-only`, `demo-1/expense-check`, `demo-2/delivery-fee` |
| `facilitator-guide.md` | Agenda, timings, pre-session checklist, common lab problems |
