# Demo 0 — emoji-only

**Idea:** the same instruction you kept pasting, written down once.

## Step A — feel the pain (no skill installed)
1. In a new chat, paste: `Reply to everything using only emoji — no words.`
2. Ask: `How do I feel after three coffees?`
3. Open a **new chat** and ask the same question. The instruction is gone — you'd have to paste it again.

## Step B — install the skill, then try
- `Emoji mode please: how was your weekend?`
- `Emoji mode: explain what a skill is.`
- Open another new chat — it still works. Written once, loaded every time.

## Things to notice
- The `description` decides *when* the skill is used. Try a prompt that doesn't mention emoji — does it trigger?
- Edit the body (e.g. "always end with 🙏") and see the behaviour change.
